What every package includes

Files you can load, and the record of every check they passed.

A package is the same resolved data the lenses read, without the lenses. It arrives as files, with the key that joins them and the paperwork that says where each record came from.

  • Parquet and CSV files. A single DuckDB file on request, so one open gives you every table.
  • Molecule crosswalk. Every drug-level record carries the same canonical molecule key, so drug tables join on one column; provider, plan, site and population tables keep their own registry keys and join through the crosswalk.
  • Vintage manifest. Names each register release in the package, with the period it covers.
  • Integrity report. Record counts per table, key coverage, null checks and the checks each table passed.
  • Refresh as each register is released. New files, a new manifest, a new report. Nothing is re-estimated.
  • Licensed for internal analytical use. Source terms confirmed per package before delivery.

Questions we are asked

Before you request a package.

What format does it come in?

Parquet and CSV, one file per table, with a manifest listing every file. A single DuckDB file on request, so the whole package opens in one step. Column names and types are the same across formats.

How is it refreshed?

Each register is re-read when its next release is published. You receive the new files, a new vintage manifest naming the release, and a new integrity report with the updated counts. Earlier vintages are kept, not overwritten.

Can we join it to our data?

Yes. Every record carries the canonical molecule key, and the reference package supplies the codes and crosswalks that map your product, provider and plan identifiers onto the same keys. Join on one column, not on names.

Can we buy one family only?

Yes. The six Atlas packages above are each one or more families, and a single family can be taken on its own. The two trade packages are separate. The full Atlas is for teams that want everything on one key.

Tell us which package.

Name the package or the families you need, and what you will load them into. We confirm the source terms, the current vintage and the delivery format, and reply with what the package contains.
