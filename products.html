Questions we are asked

Before you choose.

Do all three platforms share the data?

Yes. All three read the same resolved data layer, keyed on one canonical molecule key. A number in a lens, a number in the trade explorer and a number in an Ask answer are the same number, with the same source and vintage.

Can I start with one platform?

Yes. Each platform can be taken on its own. Most teams start with the one closest to their question and add the others later, on the same deployment, without moving any data.

Do packages include the intelligence layer?

No. A package is files only: harmonised data, a molecule crosswalk, a vintage manifest and an integrity report. The lenses, the Data Atlas and Ask are part of platform access or the data + platform option.

Can a package become a platform later?

Yes. The files in a package carry the same keys the platforms use, so a team that starts with the data can add the platform on top without rebuilding anything. The same applies in reverse: platform access can be extended with the files.
